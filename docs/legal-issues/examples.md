# دليل ربط المسألة القانونية بالقانون المناسب

## هدف الدليل

يساعد هذا الدليل على ربط كل مسألة قانونية بنوعها، والجهة المختصة، والقانون أو المواد القانونية المناسبة داخل هذا المستودع.

## خطوات تحديد المسألة

### الخطوة الأولى: نوع المسألة

| نوع المسألة | القانون أو المجال المقابل |
|------------|---------------------------|
| نزاع ملكية أو عقود | القانون المدني |
| سرقة أو اعتداء أو تزوير | قانون العقوبات |
| خلاف عمالي | قانون العمل |
| خلاف تجاري أو شركة | القانون التجاري |
| طلاق أو حضانة أو نفقات | قانون الأحوال الشخصية |
| إيجار أو ملكية عقارية | قانون الإيجار / العقارات |
| مخالفة إدارية | الأنظمة الإدارية |

### الخطوة الثانية: البحث في المستودع

- افتح قسم القوانين
- اختر المجال المناسب
- اقرأ الفصول والمواد ذات الصلة
- راجع المراجع

### الخطوة الثالثة: التقييم العملي

عند اتخاذ القرار، أحضر:
- عقد أو سند
- محضر أو رسالة
- شهود أو أدلة
- تاريخ الوقائع

## ملاحظة حرجة

هذا الدليل لا يقدّم مشورة قانونية محددة، بل يعرّف المسار الصحيح للبحث، والتحقق، والرجوع إلى النصوص القانونية.
