# مرحباً بك في مكتبة وزارة العدل السورية الرقمية

## نظرة عامة

هذه المكتبة الرقمية توفر موارد شاملة عن القوانين والأنظمة والمراجع القانونية السورية، بهدف تسهيل الوصول إلى المعلومات القانونية وتنظيمها بطريقة علمية وواضحة.

## أبرز الأقسام

### 1. [القوانين والتشريعات](./laws/README.md)
مجموعة من القوانين واللوائح الأساسية النافذة مع تصنيفها حسب المجال.

### 2. [الأنظمة واللوائح](./regulations/README.md)
القرارات والأنظمة الإدارية والتعليمات التنفيذية ذات العلاقة بالعمل القضائي والإداري.

### 3. [المراجع والمصادر](./references/README.md)
مصادر مرجعية، معاجم، وأدلة قانونية مناسبة للبحث والدراسة.

### 4. [التصنيفات القانونية](./categories.md)
نظرة شاملة على مجالات القوانين والمواضيع القانونية المثبتة في المكتبة.

### 5. [من نحن](./about.md)
تعريف مختصر بغاية المشروع وبنائه وأهدافه.

### 6. [تواصل معنا](./contact.md)
بيانات التواصل وطرق الإرسال للمقترحات أو الملاحظات.

## طريقة الاستخدام

- ابدأ من الأقسام الأساسية لتصفح القوانين أو الأنظمة
- استخدم معجم المصطلحات للتعرف على المفردات القانونية
- راجع القوالب قبل إضافة محتوى جديد
- تابع تحديثات المشروع عبر المستودع GitHub

## المساهمات

نرحب بالمساهمات الراغبة في إغناء المكتبة من خلال:
- إضافة قوانين أو أنظمة جديدة
- تحسين الهيكل أو التنسيق
- توثيق المعلومات بصورة دقيقة
- توضيح الروابط والمراجع
